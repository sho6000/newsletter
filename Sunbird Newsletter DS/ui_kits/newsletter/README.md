# UI kit — Sunbird Newsletter

Three surfaces, all composed from this system's components; nothing is re-implemented locally.

| File | Surface |
| --- | --- |
| `index.html` | Shell with tab nav; click-through between the three screens |
| `IssueScreen.jsx` | A full edition, in the July 2026 running order: masthead, Spotlight, Product Update grid, microsite pointer, Join the Collective, footer |
| `ArchiveScreen.jsx` | Edition index; clicking any row opens the edition |
| `SubscribeScreen.jsx` | Marigold subscribe page with a working (fake) confirm state |

Structure and copy follow the July 2026 edition PDF; brand vocabulary comes from sunbird.org and the Sunbird ED V-ii deck. Story imagery is intentionally left blank — no product photography was supplied.
