One-line: the pill-shaped CTA used at the end of newsletter blocks and on Sunbird pages.

```jsx
<Button href="https://sunbird.org" iconAfter="→">Read the story</Button>
<Button variant="secondary" size="sm">Subscribe</Button>
```

Variants: `primary` (solid clay), `secondary` (clay outline — use on marigold), `ghost` (inline text link with arrow), `alert` (vermilion, reserve for time-bound notices). Never place a primary clay button directly on a vermilion surface.
